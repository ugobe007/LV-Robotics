================================================================================
                      ERROR SCENARIO REFERENCE
================================================================================

VALIDATION ERRORS (user action required):
  1. Invalid image format  → Show format + list supported
  2. Invalid video format  → Show format + list supported
  3. Image too large       → Show size, limit, compression tip
  4. Video too large       → Show size, limit, shorter clip tip

UPLOAD ERRORS (with recovery):
  5. Network unavailable   → Fallback to localStorage, show message
  6. Connection timeout    → Fallback to localStorage, show message
  7. Bucket not found      → Fallback to localStorage, show setup guide
  8. Permission denied     → Show "sign in" message
  9. File too large (413)  → Show server rejection message
 10. Rate limiting (429)   → Show "server busy" message
 11. Public URL failed     → Show "URL generation" error
 12. Generic upload error  → Fallback to localStorage

MEDIA DISPLAY ERRORS (graceful degradation):
 13. Image 404/not found   → Show placeholder + error message
 14. Video 404/not found   → Hide + show error message

DATABASE ERRORS (permission checks):
 15. Post not found        → Show "already deleted" message
 16. Permission denied     → Show "cannot delete" message
 17. DB connection error   → Show generic error

PROCESSING ERRORS (data corruption):
 18. File read failed      → Show "read error" message
 19. Base64 invalid        → Show "corrupted" message
 20. Base64 empty          → Show "corrupted" message
 21. Base64 decode error   → Show "corrupted" message

SESSION ERRORS (authentication):
 22. Not signed in         → Prompt to sign in, offer continue without media
 23. Session expired       → Prompt to sign in

URL ERRORS (invalid links):
 24. Invalid URL format    → Show full URL instead of domain

================================================================================
                      FALLBACK BEHAVIOR
================================================================================

When Supabase upload fails:
  1. Image/Video still processed locally
  2. Stored in browser localStorage
  3. User sees post immediately (temporary)
  4. If user posts without signing in, stored locally only
  5. When signed in again, post can be re-uploaded to cloud

localStorage Key:
  "lvrobotics_posts" → Contains all local posts

Fallback Display:
  - Local image shows data URL (works offline)
  - Can still be viewed until user clears cache
  - Will be replaced with cloud version if re-uploaded

================================================================================
                      COMMON USER ERRORS & FIXES
================================================================================

ERROR: "Invalid image format: image/bmp"
FIX: Use supported format: JPEG, PNG, GIF, WebP, or SVG

ERROR: "Image is too large: 15.4MB"
FIX: Compress at https://tinypng.com or reduce resolution

ERROR: "Video is too large: 65.2MB"
FIX: Upload shorter clip or compress video first

ERROR: "Please sign in to upload images"
FIX: Click "Sign in to post" button at top of page

ERROR: "Network error: Could not connect"
FIX: Check internet connection, wait a moment, try again

ERROR: "Permission denied: You do not have permission"
FIX: Make sure you're signed in correctly

ERROR: "Image failed to load" / "Video failed to load"
FIX: File may have been deleted, try refreshing page

ERROR: "Could not delete post"
FIX: May already be deleted, refresh page to confirm
