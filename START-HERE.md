## 🎯 Quick Start (5 Minutes)

### Step 1: Open in Visual Studio Code
1. Open VS Code
2. File → Open Folder
3. Select this `LV-Robotics` folder

### Step 2: Install Live Server
1. Click Extensions icon (left sidebar)
2. Search "Live Server"
3. Install it
4. Close and reopen VS Code

### Step 3: Launch Your Site
1. Right-click `index.html`
2. Select "Open with Live Server"
3. **🎉 Your website is now running!**

### Step 4: Make Your First Edit
1. In `index.html`, find line 52
2. Change the hero text
3. Save (Ctrl+S)
4. Watch it update automatically in your browser!

## 🌐 Making It Live

### Option 1: GitHub Pages (Recommended - FREE!)

**Step 1:** Create GitHub Account
- Go to github.com
- Sign up (it's free!)

**Step 2:** Install Git
- Windows: Download from git-scm.com
- Mac: Already installed or use Homebrew
- Test: Open terminal, type `git --version`

**Step 3:** Upload Your Site
Open VS Code terminal (Ctrl+` or Cmd+`) and type:

```bash
cd /path/to/LV-Robotics
git init
git add .
git commit -m "Initial website"
```

Then on GitHub:
1. Click "New Repository"
2. Name it "LV-Robotics"
3. Copy the commands GitHub shows you
4. Paste in VS Code terminal

**Step 4:** Enable GitHub Pages
1. Go to your repository Settings
2. Click "Pages" in sidebar
3. Select "main" branch
4. Click Save
5. Wait 2 minutes
6. **Your site is live!** 🎉

URL will be: `https://YOUR-USERNAME.github.io/LV-Robotics/`

### Option 2: Other Hosting (Also FREE!)
- **Netlify:** Drag and drop your folder
- **Vercel:** Connect your GitHub repo
- **000webhost:** Free traditional hosting

See [DEPLOYMENT-CHECKLIST.md](DEPLOYMENT-CHECKLIST.md) for details!

## 🆘 Troubleshooting

### "Live Server won't start"
✅ Make sure extension is installed
✅ Restart VS Code
✅ Right-click `index.html` specifically

### "My changes aren't showing"
✅ Save file (Ctrl+S)
✅ Hard refresh browser (Ctrl+Shift+R)
✅ Check browser console (F12) for errors

### "Images not appearing"
✅ File names match exactly (case-sensitive!)
✅ Images are in `images/` folder
✅ File extensions are correct (.jpg not .jpeg, etc.)

### "Mobile menu not working"
✅ JavaScript file is loaded
✅ Check console (F12) for errors
✅ Try refreshing page

**Still stuck?** Open the appropriate documentation file above!
